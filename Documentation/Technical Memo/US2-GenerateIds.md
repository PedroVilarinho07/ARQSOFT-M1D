* US2 - Generating Lending and Authors ID


| Aspect                                                                                                                                                                                                                                                                                                                  | Details                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Issue**                                                                                                                                                                                                                                                                                                               | Need to generate unique identifiers for authors and lendings in various formats as per different specific requirements. And changing the alg at run time.                                                                                                                                                                                                                                                                                                               |
| **Problem**                                                                                                                                                                                                                                                                                                             | How to implement a system that allows the creating of multiple generate Id algorithms without changing the code base and that can be configured at runtime.                                                                                                                                                                                                                                                                                                             |
| **Summary of Solution**                                                                                                                                                                                                                                                                                                 | Adopt the following tactics: Factories, use intermediary, defer binding.                                                                                                                                                                                                                                                                                                                                                                                                |
| **Factors**                                                                                                                                                                                                                                                                                                             | Compliance with external standards or internal requirements for formatting identifiers. Integration with existing systems requiring specific formats.                                                                                                                                                                                                                                                                                                                   |
| **Solution**                                                                                                                                                                                                                                                                                                            | Use an Intermediary: Use a Manager to load dynamically the components, based on configuration. In spring boot we can use the profile for that. Abstract Common Services: Define a common interface that will be used by all generate Ids algorithms. Defer Binding: Use a configuration file (application.properties) to specify witch algorithm to use. Factories: Implement a Factory so that the responsibility of generating IDs is removed from the service layer. |                                                                                                                                                             |
| **Motivation**                                                                                                                                                                                                                                                                                                          | Adaptability and capability to meet various requirements without needing to alter the core system.                                                                                                                                                                                                                                                                                                                                                                      |
| **Alternatives**                                                                                                                                                                                                                                                                                                        | The generation of the ids will be made in the service layer.                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Pending Issues**                                                                                                                                                                                                                                                                                                      | How to define the interfaces and modules that allow future extensions without incompatibilities. What are the Id formats to implement?                                                                                                                                                                                                                                                                                                                                  |

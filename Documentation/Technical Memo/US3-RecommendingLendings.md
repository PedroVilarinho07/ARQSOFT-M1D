* US 3 - Recomending Lendings

| Aspect                  | Details                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|-------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Issue**               | Provide personalized lending recommendations based on variable specifications and in real-time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | 
| **Problem**             | How to choose a recommendation on run time. How to deal with different recommendations needing different data. How to create a system that can be extended to more recommendation algorythms.                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Summary of Solution** | Adopt the following tactics: Use intermediary, defer binding, Abstract Common Services. Also, the algorithms will have direct connection to the repositories.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Factors**             | Variety of user preferences and the need for dynamic adaptation to changes in inventory or user behavior.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Solution**            | Use an Intermediary: Use a Manager to load dynamically the components, based on configuration. In spring boot we can use the profile for that. Abstract Common Services: Define a common interface that will be used by all recommendation algorithms. Defer Binding: Use a configuration file (application.properties) to specify witch algorithm to use. Different recommendation will need new data, how will the algorithm have access to the data? Create a specific service to implement the recommendation system, this service will get the necessary data by making calls to the repo. |
| **Motivation**          | Improving user experience and increasing the use of library resources through relevant recommendations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Alternatives**        | The access of the necessary data will be made with callbacks where the service gives its instance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Pending Issues**      | What criteria or user data will the recommendation be based on?                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

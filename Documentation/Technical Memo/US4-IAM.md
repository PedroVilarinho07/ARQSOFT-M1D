* US 4 - Adopting different IAM


| Aspect               | Details                                                                                                                                                                                                                                                                                                                                                                                                             |
|----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Issue**            | Adopting different IAM providers. And changing the IAM at run time.                                                                                                                                                                                                                                                                                                                                                 | 
| **Problem**          | How to change the IAM at run time through configuration. How to implement adaptability and flexibility in the system.                                                                                                                                                                                                                                                                                               |
| **Summary of Solution** | Adopt the following tactics: use intermediary, defer binding.                                                                                                                                                                                                                                                                                                                                                       |
| **Factors**          | Diversity of users with different preferences for authentication services; the need to manage identities securely and scalably.                                                                                                                                                                                                                                                                                     |
| **Solution**         | Use an Intermediary: Use a Manager to load dynamically the components, based on configuration. In spring boot we can use the profile for that. Each. Defer Binding: Use a configuration file (application.properties) to specify witch IAM provider to use so that at runtime, the system reads this configuration and loads the corresponding implementation. This allows to change the IAM without changing the code. |
| **Motivation**       | Flexibility for end-users and increased security by delegating authentication to specialized providers.                                                                                                                                                                                                                                                                                                             |
| **Alternatives**     | No good alternatives.                                                                                                                                                                                                                                                                                                                                                                                               |
| **Pending Issues**   | What IAMs to implement?                                                                                                                                                                                                                                                                                                                                                                                             |

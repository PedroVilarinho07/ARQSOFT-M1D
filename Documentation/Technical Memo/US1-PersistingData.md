* US1 - Persisting Data


| Aspect                  | Details                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Issue**               | Persisting data in different data models and SGBD. And changing the DBMS at run time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Problem**             | The current design does not allow for easy extensibility or configurability, limiting the ability to switch or add new functionalities in response to client-specific needs. This constraint impacts maintainability and adaptability, as any new implementation requires modifications to core code.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Summary of Solution** | Adopt the following tactics: reduce coupling, use intermediary, abstract common service, defer binding.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Factors**             | Different data types and operational requirements necessitate support for multiple databases; DBMS choice may depend on factors like cost, performance, and support for transactions or clients preferences.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Solution**            | Reduce coupling: Minimize dependencies between components by ensuring that each module interacts with others through interfaces. Use an Intermediary: Use a Manager to load dynamically the components, based on configuration. In spring boot we can use the profile for that. Abstract Common Services: Define a common interface for database repository functionality. Each repository implementation (e.g., for MySQL, MongoDB) will adhere to this interface, ensuring that components using these repositories remain unaffected by changes in the specific database implementation. Defer Binding: Use a configuration file (application.properties) to specify witch database to use so that at runtime, the system reads this configuration and loads the corresponding database implementation. This allows to change the database without changing the code. |
| **Motivation**          | Flexibility to choose or switch storage technology as needed without significant refactoring costs or downtime. Also, adopt the same code base for different clients that have constraints on the same data models and DBMS.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Alternatives**        | No good alternatives.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Pending Issues**      | What data models and DBMS should be supported? What are the parts of the system that require modifications? How long and difficult will be the  refactoring of current solution to adopt other persistence data models and DBMS?                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |                                                                                                                                                                                                                                                       |

* US2 - Generating Lending and Authors ID


| Aspect               | Details |
|----------------------|--------|
| **Problem**          | Need to generate unique identifiers for authors and lendings in various formats as per different specific requirements. |
| **Summary of Solution** | Develop a configurable ID generation service that supports multiple formats and specifications, integrable at runtime. |
| **Factors**          | Compliance with external standards or internal requirements for formatting identifiers; integration with existing systems requiring specific formats. |
| **Solution**         |  |
| **Motivation**       | Adaptability and capability to meet various requirements without needing to alter the core system. |
| **Alternatives**     | Use of a single ID generation system with less flexibility or higher code complexity. |
| **Pending Issues**   | Defining interfaces and modules that allow future extensions without disruptions or incompatibilities. |

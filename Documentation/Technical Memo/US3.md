* US 3 - Recomending Lendings

| Aspect               | Details                                                                                                    |
|----------------------|------------------------------------------------------------------------------------------------------------|
| **Problem**          | Provide personalized lending recommendations based on variable specifications and in real-time.            |
| **Summary of Solution** | Implement a configurable recommendation system that can adapt to different logics and criteria.            |
| **Factors**          | Variety of user preferences and the need for dynamic adaptation to changes in inventory or user behavior.  |
| **Solution**         |                                                                                                |
| **Motivation**       | Improving user experience and increasing the use of library resources through relevant recommendations.    |
| **Alternatives**     | Static recommendation systems based on popularity or new releases, without adaptation to individual needs. |
| **Pending Issues**   | Continuous integration of new data into the model and constant evaluation of recommendation efficacy.      |
